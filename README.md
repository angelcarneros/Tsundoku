# Tsundoku

**Your personal space for anime and manga.**

Track what you watch and read, organize your collection, write reviews, and share your favorites with others.

Tsundoku is a personal project built from scratch to learn and improve my **HTML**, **CSS**, and **JavaScript** skills through practical web development.

The project aims to create a clean, customizable, and community-driven web application for tracking anime and manga, while exploring new technologies and gradually implementing more advanced features.

---

## ✨ About the Project

Tsundoku aims to provide a simple and enjoyable way to keep track of your anime and manga journey.

Inspired by platforms such as MyAnimeList and AniList, the project focuses on personal organization, customization, and social interaction.

Whether you're watching a new anime, reading your favorite manga, or looking for your next series, Tsundoku aims to keep everything in one place.

## 🚀 Planned Features

### 📖 Anime & Manga Tracking
- Search and discover anime and manga.
- Add titles to personalized lists.
- Track your watching and reading progress.
- Organize titles by status: Watching/Reading, Completed, On Hold, Dropped, and Planned.
- Give personal ratings to each title.

### ⭐ Reviews & Ratings
- Write and publish personal reviews.
- Rate anime and manga.
- Discover reviews written by other users.
- Share opinions and recommendations.

### 👤 User Profiles
- Create an account and customize your profile.
- Display favorite anime and manga.
- Showcase personal lists and reviews.
- Choose between public and private lists.

### 🌐 Community & Friends
- Search for other users.
- Send and accept friend requests.
- Explore public anime and manga lists.
- Discover what your friends are watching and reading.

### 🎨 Customization
- Clean, modern, and responsive interface.
- Personalized user experience.
- Light and dark themes.

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| HTML5 | Semantic structure |
| CSS3 | Styling and responsive design |
| JavaScript | Interactivity and application logic |
| Jikan API | Anime and manga information |
| Supabase (planned) | Authentication and database |

### Anime & Manga Data

Tsundoku uses the [Jikan API](https://jikan.moe/) to retrieve information from MyAnimeList, including:

- Titles and cover images
- Synopses and genres
- Community ratings and popularity
- Episodes, chapters, and publishing information
- Trailers, when available

Personal reviews, ratings, user profiles, and lists will be managed separately by Tsundoku.


## 📌 Project Status

**Early Development**

Tsundoku is currently a personal learning project under active development. Features, technologies, and design decisions may change as the project evolves.

The goal is to build the application progressively while improving my skills in web development.
